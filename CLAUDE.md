# Moxa · bot de citas por WhatsApp

`web/` es la API y web de pruebas (Next.js + Neon + OpenAI) y `bot/` el bot de WhatsApp con Evolution; ver `README.md`. Vercel: `moxa-web` (subido por CLI, sin conexión a Git). El asistente de Zamalloa (`zamalloa-bot/` en el repo `portfolio`) es un duplicado adaptado de esto.

Este repo es solo para este proyecto. Si el encargo es de otro proyecto, para y avisa: cada proyecto tiene su repo y se trabaja en una sesión abierta solo con ese repo (mapa completo en `REPOS.md` del repo `portfolio`). `main` es lo publicado; se trabaja en ramas `claude/…`.
